# Navigation Icons

## How to Add Your Icons

Save your 4 glassmorphic navigation icons to this directory with these exact filenames:

1. **today.png** - Yellow/gold star icon (for Today tab)
2. **calendar.png** - Green calendar icon (for Calendar tab)
3. **goals.png** - Purple target/bullseye icon (for Goals tab)
4. **settings.png** - Blue/gray gear icon (for Settings tab)

## Icon Specifications
- **Format**: PNG with transparency
- **Recommended size**: 256x256px or higher
- **Style**: Glassmorphic/3D with soft shadows and gradients
- **Background**: Transparent

## Already Implemented
The Navigation component (`/components/Navigation.tsx`) is already configured to use these icons.

Once you save the 4 PNG files in this directory, they will automatically appear in the bottom navigation bar!
